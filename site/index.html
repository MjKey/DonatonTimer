Dok-панель для OBS

Компактная мини-панель управления, встраиваемая прямо в интерфейс OBS Studio. Больше не нужно переключаться между окнами во время игры.

Установка и первый запуск

Скачайте установочный файл DonatonTimer_v3.0.8_Setup.exe или портативную версию для Windows, либо AppImage для Linux.

  1. Запустите приложение. При первом открытии появится главное окно с таймером в ретро-стиле.
  2. Нажмите на поле времени, чтобы выставить стартовое значение (например, 01:00:00 для 1 часа).
  3. Нажмите кнопку Старт для проверки отсчёта.
При первом запуске Windows Defender или SmartScreen может показать предупреждение о новом файле — нажмите «Подробнее» → «Выполнить в любом случае».
2
Настройка DonationAlerts (Centrifugo v2)

В DonatonTimer v3.0.8 подключение к DonationAlerts работает через актуальный протокол Centrifugo с автообновлением токена доступа.

  1. Войдите в личный кабинет DonationAlerts.
  2. Перейдите в меню слева: Оповещения → группа Виджеты → найдите вашу вариацию оповещений.
  3. Нажмите «Показать ссылку для встраивания» и скопируйте её (или скопируйте токен виджета из конца ссылки).
  4. В приложении DonatonTimer откройте Настройки (шестерёнка) → вкладка DonationAlerts.
  5. Вставьте скопированную ссылку в поле «Токен или ссылка на виджет».
  6. Выберите домен сервиса: donationalerts.com или donationalerts.ru.
  7. Укажите курс начисления времени: например, 600 RUB = 60 мин (или 100 RUB = 10 мин).
  8. Включите тумблер «Включить DonationAlerts» и нажмите Сохранить. Индикатор статуса станет зелёным.
3
Настройка CloudTips

Сервис безналичных чаевых и донатов CloudTips подключается через ссылку потока оповещений:

  1. Войдите в кабинет CloudTips.
  2. Перейдите в раздел «Стримерам» → подраздел «Оповещения».
  3. Скопируйте ссылку на поток оповещений вида: https://stream.cloudtips.ru/n/YOUR_CHANNEL_ID.
  4. В DonatonTimer откройте Настройки → вкладка CloudTips.
  5. Вставьте скопированную ссылку в поле «Ссылка на оповещения».
  6. Включите тумблер и нажмите Сохранить. Донаты с банковских карт и СБП будут автоматически продлевать таймер!
4
Настройка DonatePay

DonatePay подключается через персональный API-ключ пользователя:

  1. Войдите в аккаунт на сайте DonatePay.ru.
  2. Перейдите в Настройки → вкладка API (или откройте https://donatepay.ru/page/api).
  3. Скопируйте ваш API-ключ.
  4. В DonatonTimer откройте Настройки → вкладка DonatePay.
  5. Вставьте ключ в поле ввода, активируйте сервис и нажмите Сохранить.
5
Настройка Donate.Stream

Интеграция с сервисом Donate.Stream:

  1. Войдите в личный кабинет Donate.Stream.
  2. Перейдите в раздел Виджеты → Оповещения о донатах.
  3. Скопируйте ключ или полную ссылку на виджет оповещений.
  4. В DonatonTimer откройте Настройки → вкладка Donate.Stream.
  5. Вставьте ключ в соответствующее поле, включите тумблер и нажмите Сохранить.
6
Настройка Donatty

Подключение виджета Donatty:

  1. Войдите в личный кабинет Donatty.
  2. В разделе виджетов скопируйте ссылку на виджет оповещений (она содержит параметры ref=...&token=...).
  3. В DonatonTimer перейдите в Настройки → вкладка Donatty.
  4. Вставьте ссылку (программа автоматически извлечёт токен) или вставьте сам токен.
  5. Выберите назначенный API-сервер (по умолчанию api-014.donatty.com) и нажмите Сохранить.
7
Настройка DonateX

DonateX использует ссылки на недавние сообщения и цель сбора средств:

  1. В панели DonateX откройте виджеты.
  2. Скопируйте ссылку на недавние сообщения (Recent URL) и сбор средств (Group URL).
  3. В DonatonTimer откройте Настройки → вкладка DonateX.
  4. Вставьте ссылки в соответствующие поля и нажмите Сохранить.
8
Интеграция со Streamer.bot

Привязывайте платные подписки, фолловы, баллы канала Twitch и YouTube к прибавлению времени:

  1. В программе Streamer.bot перейдите в Servers/Clients → WebSocket Server и включите Auto Start (по умолчанию порт 8080).
  2. В DonatonTimer откройте Настройки → вкладка Streamer.bot, укажите адрес ws://127.0.0.1:8080/ и включите сервис.
  3. Нажмите «Добавить привязку»: выберите платформу (Twitch / YouTube), тип события (Sub, Gift Sub, Cheer, Channel Points) → задайте эквивалентную сумму в рублях.
9
Вывод оверлея в OBS Studio

DonatonTimer поднимает локальный веб-сервер, который отдаёт готовый прозрачный оверлей:

  1. В OBS Studio в списке источников сцены нажмите + и выберите Браузер (Browser Source).
  2. В поле URL укажите адрес:
    OBS URL Оверлея
    http://127.0.0.1:7575/timer
  3. Укажите ширину и высоту (рекомендуется 600 × 180).
  4. Оверлей сразу отобразит красивый таймер со стилями, настроенными в CSS генераторе!
10
Управление через Dok-панель OBS Studio

Управляйте таймером прямо из окна OBS без необходимости сворачивать игру или стрим:

  1. В верхнем меню OBS Studio выберите Вид → Dok-панели → Пользовательские dok-панели браузера.
  2. В столбце «Имя» введите, например: Донатон Таймер.
  3. В столбце «URL-адрес» введите:
    URL Dok-панели
    http://127.0.0.1:7575/mini
  4. Нажмите Применить. Появится компактная панель, которую можно закрепить в любом месте окна OBS.
11
Управление со смартфона по QR-коду

Контролируйте таймер, отойдя от компьютера или прямо с дивана:

  1. Убедитесь, что смартфон и компьютер подключены к одной Wi-Fi сети.
  2. В DonatonTimer нажмите кнопку QR-код на панели управления.
  3. Наведите камеру смартфона на QR-код и откройте ссылку.
  4. В браузере откроется мобильная веб-панель со всеми кнопками управления и топом донатеров в реальном времени.

Частые вопросы и диагностика (FAQ)
  • ❓ В OBS горит чёрный экран или ошибка соединения:
    Убедитесь, что приложение DonatonTimer запущено. Проверьте в журнале приложения, не был ли занят порт 7575. Если порт был занят, приложение автоматически пробует 7576.
  • ❓ Донаты приходят в DonationAlerts, но таймер не прибавляется:
    Проверьте статус подключения во вкладке DonationAlerts. Если статус красный, обновите ссылку виджета оповещений и проверьте, указан ли правильный курс конвертации рублей в минуты.
  • ❓ Телефон не открывает панель по QR-коду:
    Проверьте брандмауэр Windows (Windows Firewall) — при первом запуске разрешите приложению доступ к частным сетям (Private Networks). Телефон и ПК должны находиться в одной локальной подсети.
Разработчикам

Документация локального API

Создавайте собственные HTML-виджеты для OBS, внешние контроллеры или чат-боты, общаясь с таймером по WebSocket.

1
Архитектура портов и адреса

DonatonTimer поднимает два локальных сервиса:

Адрес Тип Назначение
http://127.0.0.1:7575/timer HTTP Готовая страница таймера со стилями из приложения
http://127.0.0.1:7575/dashboard HTTP Полнофункциональная панель управления и статистика
http://127.0.0.1:7575/mini HTTP Компактная мини-панель для dok-панели OBS
ws://127.0.0.1:3434/ WebSocket Двусторонний обмен данными, статус таймера и команды
Все данные о времени и события передаются через WebSocket на порту 3434. Путь — корень / (не /ws).
2
События сервера (Server → Client)

Сервер транслирует два типа сообщений всем подключённым WebSocket клиентам:

1. Обновление времени: update_timer

Отправляется каждую секунду при активном отсчёте, а также сразу при паузе, запуске или добавлении времени:

JSON Сообщение
{
  "action": "update_timer",
  "duration": 3661
}

duration — общее количество оставшихся секунд (целое неотрицательное число). Например, 3661 соответствует 01:01:01.

2. Статистика донатов: update_donations

Отправляется при поступлении новых донатов и при первом подключении клиента:

JSON Сообщение
{
  "action": "update_donations",
  "recentDonations": [
    { "username": "Viewer1", "minutesAdded": 15 },
    { "username": "Viewer2", "minutesAdded": 5 }
  ],
  "topDonators": {
    "Viewer1": 45,
    "Viewer2": 20
  }
}
3
Команды управления (Client → Server)

Для управления таймером отправляйте JSON-сообщения в открытый WebSocket:

Команда (JSON) Описание действия
{"action": "start"} Запустить отсчёт таймера (если остаток времени > 0)
{"action": "stop"} Приостановить таймер (пауза)
{"action": "change_time", "seconds": 300} Добавить 5 минут (+300 секунд) к остатку времени
{"action": "change_time", "seconds": -60} Вычесть 1 минуту (-60 секунд) из остатка времени
JavaScript Пример отправки команды
const socket = new WebSocket('ws://127.0.0.1:3434/');

socket.onopen = () => {
  // Добавить 10 минут (600 секунд)
  socket.send(JSON.stringify({
    action: 'change_time',
    seconds: 600
  }));
};
4
Готовый шаблон собственного HTML-виджета

Вы можете сохранить данный код в файл widget.html на своём компьютере, отредактировать под свой стрим и добавить в OBS как Локальный файл источника «Браузер»:

widget.html
<!doctype html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width,initial-scale=1">
  <title>Кастомный виджет DonatonTimer</title>
  <style>
    html, body { margin: 0; background: transparent; overflow: hidden; }
    body { font-family: "Segoe UI", Arial, sans-serif; color: #fff; }
    #timer {
      display: inline-block;
      padding: 14px 24px;
      border-radius: 16px;
      background: rgba(15, 18, 28, 0.85);
      border: 2px solid #8b5cf6;
      font-size: 68px;
      font-weight: 700;
      font-variant-numeric: tabular-nums;
      line-height: 1;
      text-shadow: 0 0 20px rgba(139, 92, 246, 0.6);
    }
    #status { margin: 6px 12px; font-size: 13px; color: #94a3b8; }
    html[data-connected="false"] #timer { opacity: 0.5; border-color: #ef4444; }
  </style>
</head>
<body>
  <div id="timer">--:--:--</div>
  <div id="status">Подключение…</div>

  <script>
    const WS_URL = 'ws://127.0.0.1:3434/';
    const timer = document.getElementById('timer');
    const status = document.getElementById('status');
    let socket;
    let retry;

    function formatTime(total) {
      const hours = Math.floor(total / 3600);
      const minutes = Math.floor(total / 60) % 60;
      const seconds = total % 60;
      return [hours, minutes, seconds]
        .map(v => String(v).padStart(2, '0'))
        .join(':');
    }

    function connect() {
      socket = new WebSocket(WS_URL);
      socket.onopen = () => {
        document.documentElement.dataset.connected = 'true';
        status.textContent = '';
      };
      socket.onmessage = (event) => {
        try {
          const msg = JSON.parse(event.data);
          if (msg && msg.action === 'update_timer' && typeof msg.duration === 'number') {
            timer.textContent = formatTime(msg.duration);
          }
        } catch (e) {}
      };
      socket.onclose = () => {
        document.documentElement.dataset.connected = 'false';
        status.textContent = 'Потеря связи — переподключение…';
        clearTimeout(retry);
        retry = setTimeout(connect, 1500);
      };
      socket.onerror = () => socket.close();
    }

    connect();
  </script>
</body>
</html>
