Идеальный таймер для твоего
Донатон-марафона

Бесплатный и удобный таймер, который сам прибавляет время за донаты с DonationAlerts, CloudTips, DonatePay и других платформ. Легко встраивается в OBS, настраивается под твой стиль и управляется прямо с телефона!

Возможности

Всё необходимое для марафона

Сделано с душой для ваших стримов — просто запустите, настройте под себя и не переживайте во время эфира.

Все сервисы сразу

Подключайте DonationAlerts, CloudTips, DonatePay, Donate.Stream, DonateX и Donatty хоть одновременно. Ни один донат не пройдёт мимо таймера.

CSS Генератор стилей

14 готовых пресетов (Cyberpunk, Matrix, Kawaii и другие), шрифты Google Fonts, свои цвета для часов, минут и секунд, а также мягкое неоновое свечение.

Управление со смартфона

Отсканируйте QR-код в программе и управляйте временем, ставьте паузу или следите за топом донатеров прямо с экрана телефона.

Dok-панель для OBS

Удобная мини-панель, которая встраивается прямо в окно OBS Studio. Больше не нужно сворачивать игру или искать таймер среди десятка окон.

Связка со Streamer.bot

Привяжите платные подписки Twitch и YouTube, баллы канала или команды в чате к автоматическому добавлению времени через WebSocket.

Автосохранение

Таймер бережно сохраняет оставшееся время на лету. Даже если моргнёт свет или случайно закроется окно — ваш марафон продолжится с той же секунды.

1
Установка и первый запуск

Скачайте установщик .exe (или портативный архив) для Windows, либо AppImage/пакет для Linux.

  1. Запустите программу — перед вами сразу откроется главное окно с таймером.
  2. Кликните прямо по цифрам времени, чтобы задать стартовый отсчёт (например, 01:00:00 на 1 час).
  3. Нажмите кнопку Старт, чтобы проверить, как тикает время.
При первом запуске Windows SmartScreen может спросить, доверяете ли вы файлу — просто нажмите «Подробнее» → «Выполнить в любом случае».
2
Подключение DonationAlerts

Таймер общается с DonationAlerts по современному протоколу Centrifugo v2 и сам обновляет токен, так что ничего не отвалится посреди стрима:

  1. Зайдите в личный кабинет DonationAlerts.
  2. В меню слева откройте Оповещения → Виджеты и найдите вашу основную группу оповещений.
  3. Нажмите «Показать ссылку для встраивания» и скопируйте её целиком.
  4. В DonatonTimer откройте Настройки (шестерёнка) → вкладка DonationAlerts.
  5. Вставьте ссылку в поле «Токен или ссылка на виджет».
  6. Выберите домен, которым пользуетесь: donationalerts.com или donationalerts.ru.
  7. Настройте курс времени во вкладке «Таймер»: например, 600 RUB = 60 мин (это 10 минут за каждые 100 рублей).
  8. Включите тумблер «Включить DonationAlerts» и нажмите Сохранить. Кружок статуса на главном экране загорится зелёным!
3
Подключение CloudTips

Чтобы принимать чаевые с карт и СБП через CloudTips, понадобится ссылка на поток оповещений:

  1. Зайдите в свой кабинет CloudTips.
  2. Перейдите в раздел «Стримерам» → «Оповещения».
  3. Скопируйте ссылку на поток оповещений (она выглядит как https://stream.cloudtips.ru/n/ВАШ_ID).
  4. В DonatonTimer откройте Настройки → вкладка CloudTips.
  5. Вставьте ссылку, включите сервис и нажмите Сохранить. Готово!
4
Подключение DonatePay

Для работы с DonatePay нужен только ваш API-ключ:

  1. Войдите в аккаунт на сайте DonatePay.ru.
  2. Откройте Настройки → вкладка API (или перейдите по прямой ссылке https://donatepay.ru/page/api).
  3. Скопируйте ваш API-ключ.
  4. В DonatonTimer перейдите в Настройки → DonatePay, вставьте ключ, включите тумблер и нажмите Сохранить.
5
Подключение Donate.Stream

Настройка занимает меньше минуты:

  1. Зайдите в личный кабинет Donate.Stream.
  2. Откройте раздел Виджеты → Оповещения о донатах.
  3. Скопируйте ключ или ссылку на виджет оповещений.
  4. В DonatonTimer откройте Настройки → Donate.Stream, вставьте ключ, включите сервис и сохраните.
6
Подключение Donatty

Таймер умеет сам вытаскивать токен прямо из ссылки вашего виджета Donatty:

  1. Зайдите в личный кабинет Donatty.
  2. В разделе виджетов скопируйте ссылку на виджет оповещений (внутри неё есть параметры ref=...&token=...).
  3. В DonatonTimer откройте Настройки → Donatty и просто вставьте эту ссылку.
  4. Выберите API-сервер (обычно подходит стандартный api-014.donatty.com) и нажмите Сохранить.
7
Подключение DonateX

Для подключения DonateX понадобятся ссылки на ваши виджеты:

  1. В панели DonateX откройте раздел виджетов.
  2. Скопируйте ссылку на последние сообщения (Recent URL) и сбор средств (Group URL).
  3. В DonatonTimer откройте Настройки → DonateX, вставьте ссылки и нажмите Сохранить.
8
Связка со Streamer.bot

Хотите прибавлять время за подписки, рейды или баллы канала Twitch и YouTube? Подключите Streamer.bot:

  1. В программе Streamer.bot откройте вкладку Servers/Clients → WebSocket Server и поставьте галочку Auto Start (порт по умолчанию — 8080).
  2. В DonatonTimer зайдите в Настройки → Streamer.bot, проверьте адрес ws://127.0.0.1:8080/ и включите тумблер.
  3. Нажмите «Добавить привязку»: выберите платформу (Twitch или YouTube), нужное событие (подписка, подарочная сабка, битсы, баллы канала) и укажите, как будто сколько рублей доната оно должно приносить таймеру.
9
Вывод таймера в OBS Studio

Программа сама создаёт готовую страничку с прозрачным фоном для OBS:

  1. В OBS Studio в списке «Источники» нажмите + и выберите Браузер (Browser Source).
  2. В поле URL вставьте эту ссылку:
    OBS URL Оверлея
    http://127.0.0.1:7575/timer
  3. Укажите размер 600 × 180 (или любой удобный вам).
  4. Таймер сразу появится на сцене! А во вкладке «Внешний вид» → «Генератор стилей» вы можете менять шрифты, цвета и свечение прямо на ходу.
10
Удобная Dok-панель внутри OBS Studio

Встройте мини-пульт таймера прямо в окно OBS, чтобы не переключаться между программами во время игры:

  1. В верхнем меню OBS выберите Вид → Dok-панели → Пользовательские dok-панели браузера.
  2. В поле «Имя» напишите, например: Таймер.
  3. В поле «URL-адрес» вставьте:
    URL Dok-панели
    http://127.0.0.1:7575/mini
  4. Нажмите Применить — появится аккуратная панелька, которую можно перетащить и закрепить рядом с чатом или микшером звука.
11
Управление с телефона по QR-коду

Отошли налить чай или проводите кукинг-стрим? Управляйте таймером прямо со смартфона:

  1. Проверьте, что телефон подключён к тому же Wi-Fi, что и ваш компьютер.
  2. На главном экране DonatonTimer нажмите кнопку с иконкой QR-кода.
  3. Наведите камеру телефона на код и перейдите по ссылке.
  4. Откроется удобный мобильный пульт: можно ставить паузу, добавлять минуты и смотреть список последних донатов.
Частые вопросы (FAQ)
  • FAQВ OBS пустое место или таймер не грузится:
    Проверьте, запущена ли сама программа DonatonTimer. Также загляните в настройки таймера («Настройки портов»): если порт 7575 был занят другой программой, таймер мог переключиться на 7576.
  • FAQДонаты приходят, но время не прибавляется:
    Посмотрите на индикатор сервиса на главном экране — он должен гореть зелёным. Если он красный, обновите ссылку виджета в настройках и проверьте, задан ли курс минут во вкладке «Таймер».
  • FAQНе открывается пульт на телефоне по QR-коду:
    Чаще всего мешает Брандмауэр Windows — разрешите DonatonTimer доступ к частным сетям (Private Networks) и убедитесь, что телефон и ПК находятся в одной домашней сети.
Разработчикам

Локальное API таймера

Хотите сверстать свой уникальный HTML-виджет для OBS или прикрутить управление из чат-бота? Подключайтесь к таймеру напрямую по WebSocket.

1
Архитектура портов и адреса

DonatonTimer поднимает два локальных сервиса:

Адрес Тип Назначение
http://127.0.0.1:7575/timer HTTP Готовая страница таймера со стилями из приложения
http://127.0.0.1:7575/dashboard HTTP Полнофункциональная панель управления и статистика
http://127.0.0.1:7575/mini HTTP Компактная мини-панель для dok-панели OBS
ws://127.0.0.1:3434/ WebSocket Двусторонний обмен данными, статус таймера и команды
Все данные о времени и события передаются через WebSocket на порту 3434. Путь — корень / (не /ws).
2
События сервера (Server → Client)

Сервер транслирует два типа сообщений всем подключённым WebSocket клиентам:

1. Обновление времени: update_timer

Отправляется каждую секунду при активном отсчёте, а также сразу при паузе, запуске или добавлении времени:

JSON Сообщение
{
  "action": "update_timer",
  "duration": 3661
}

duration — общее количество оставшихся секунд (целое неотрицательное число). Например, 3661 соответствует 01:01:01.

2. Статистика донатов: update_donations

Отправляется при поступлении новых донатов и при первом подключении клиента:

JSON Сообщение
{
  "action": "update_donations",
  "recentDonations": [
    { "username": "Viewer1", "minutesAdded": 15 },
    { "username": "Viewer2", "minutesAdded": 5 }
  ],
  "topDonators": {
    "Viewer1": 45,
    "Viewer2": 20
  }
}
3
Команды управления (Client → Server)

Для управления таймером отправляйте JSON-сообщения в открытый WebSocket:

Команда (JSON) Описание действия
{"action": "start"} Запустить отсчёт таймера (если остаток времени > 0)
{"action": "stop"} Приостановить таймер (пауза)
{"action": "change_time", "seconds": 300} Добавить 5 минут (+300 секунд) к остатку времени
{"action": "change_time", "seconds": -60} Вычесть 1 минуту (-60 секунд) из остатка времени
JavaScript Пример отправки команды
const socket = new WebSocket('ws://127.0.0.1:3434/');

socket.onopen = () => {
  // Добавить 10 минут (600 секунд)
  socket.send(JSON.stringify({
    action: 'change_time',
    seconds: 600
  }));
};
4
Готовый шаблон собственного HTML-виджета

Вы можете сохранить данный код в файл widget.html на своём компьютере, отредактировать под свой стрим и добавить в OBS как Локальный файл источника «Браузер»:

widget.html
<!doctype html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width,initial-scale=1">
  <title>Кастомный виджет DonatonTimer</title>
  <style>
    html, body { margin: 0; background: transparent; overflow: hidden; }
    body { font-family: "Segoe UI", Arial, sans-serif; color: #fff; }
    #timer {
      display: inline-block;
      padding: 14px 24px;
      border-radius: 16px;
      background: rgba(15, 18, 28, 0.85);
      border: 2px solid #8b5cf6;
      font-size: 68px;
      font-weight: 700;
      font-variant-numeric: tabular-nums;
      line-height: 1;
      text-shadow: 0 0 20px rgba(139, 92, 246, 0.6);
    }
    #status { margin: 6px 12px; font-size: 13px; color: #94a3b8; }
    html[data-connected="false"] #timer { opacity: 0.5; border-color: #ef4444; }
  </style>
</head>
<body>
  <div id="timer">--:--:--</div>
  <div id="status">Подключение…</div>

  <script>
    const WS_URL = 'ws://127.0.0.1:3434/';
    const timer = document.getElementById('timer');
    const status = document.getElementById('status');
    let socket;
    let retry;

    function formatTime(total) {
      const hours = Math.floor(total / 3600);
      const minutes = Math.floor(total / 60) % 60;
      const seconds = total % 60;
      return [hours, minutes, seconds]
        .map(v => String(v).padStart(2, '0'))
        .join(':');
    }

    function connect() {
      socket = new WebSocket(WS_URL);
      socket.onopen = () => {
        document.documentElement.dataset.connected = 'true';
        status.textContent = '';
      };
      socket.onmessage = (event) => {
        try {
          const msg = JSON.parse(event.data);
          if (msg && msg.action === 'update_timer' && typeof msg.duration === 'number') {
            timer.textContent = formatTime(msg.duration);
          }
        } catch (e) {}
      };
      socket.onclose = () => {
        document.documentElement.dataset.connected = 'false';
        status.textContent = 'Потеря связи — переподключение…';
        clearTimeout(retry);
        retry = setTimeout(connect, 1500);
      };
      socket.onerror = () => socket.close();
    }

    connect();
  </script>
</body>
</html>
